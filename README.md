# Aldraheimr (2nd Edition)
Because the files for the original world were messy and inconsistent, I present to you: **Aldraheimr (2nd Edition)!**

Aldraheimr (2nd Edition) is a mythic historical fantasy based on the 9th and 10th centuries. I will try a more narrative strategy in describing things for this version, which should make things easier and more dynamic.
